# Video Studio — передача дизайна

[Сценарии в Figma](https://www.figma.com/design/ShN67dGIwD1KCI4ZoTfUyg/?node-id=9-2) · [UI Kit](https://www.figma.com/design/ShN67dGIwD1KCI4ZoTfUyg/?node-id=58-4)

45 семейств компонентов, включая 12 иконок. Экраны используют настоящие вложенные instances. Цвета, интервалы и радиусы связаны с Figma Variables; типографика — с Text Styles.

## Файлы

- `tokens.css` — семантические CSS-переменные с теми же именами, что в Figma.
- `components.json` — ID компонентов, свойства, варианты, текстовые стили и сценарии.
- `types.ts` — предлагаемый контракт данных для реализации, без привязки к фреймворку.

Это спецификация для вёрстки, а не готовые исполняемые компоненты. Code Connect не зарегистрирован: соответствующие компоненты приложения ещё не реализованы.

## Поведение

- Персонаж, одежда и локация задаются только слева. В свёрнутом меню остаются иконки с доступными подписями и подсказками.
- Свободная форма: 30 с / 1 мин / 1:30 / 2 мин. Выбор голоса убран.
- Движения: пользователь выбирает заготовки и длительность каждого выбранного элемента. Итог равен сумме. Максимум берётся из данных конкретной заготовки, превышение недоступно.
- «До 30 с» на карточках — пример, а не подтверждённое ограничение API. При интеграции подставить действительные максимумы.
- Демонстрационный ролик: 1:30 свободной формы + 2:30 движений = 4:00. Общая длительность вычисляется, отдельного общего селектора нет.
- Генерация разбита на задания до 30 секунд. Последний отрезок может быть короче, если выбранная длительность не кратна 30. Сохранять связь задания с частью/движением.
- Timeline показывает статусы каждого задания без превью: готово — голубой; в процессе — полосы; очередь — тёмный; ошибка — охра + знак. Статус не должен передаваться только цветом.
- Ошибка одного задания не удаляет готовые результаты. Повтор запускает только неудавшийся отрезок.
- Кнопка запуска закреплена снизу панели; контент выше может прокручиваться. Во время генерации остановка действует после текущего отрезка.
- Навигация прототипа демонстрирует отдельные состояния. Реальные генерация, проигрывание, сохранение и скачивание требуют реализации.

## Размеры и оформление

Базовый экран 1512 × 982. Колонки: 364 px настройки (76 px в свёрнутом виде), 424 px плеер, оставшееся место — генерация. Видео 9:16. Панель генерации и текстовые поля используют Auto Layout и Fill; основной CTA 56 px. Карточки движений вертикальные, карточки одежды компактные 240 × 286.

Тёмная графитовая тема, голубой акцент, без розового. Иконки с единой толщиной 1.5 px. Фотографии демонстрационные; портрет плеера не является результатом генерации с выбранной одеждой.

## Дорожные карты

1. Подготовка: новый проект → библиотека одежды → сценарий и длительность.
2. Генерация: свободная форма в процессе → выбор движений → движения в процессе → готовый ролик.
3. Ошибка: неудавшийся отрезок → повторная генерация, готовые отрезки сохранены.
4. Рабочее пространство: раскрытое меню → меню с иконками.

Все исходные экранные frame ID сохранены; дополнительные кадры для отдельных сценариев также собраны из instances.

## Аккаунт и кредиты

Вход: frame 103:1504. Меню пользователя поверх студии: 103:1523.
История расхода поверх студии: 103:1559. Отдельной страницы профиля нет.

AccountInput, LoginCard, AccountTrigger, AccountMenu, CreditSummary,
CreditHistory и CreditHistoryDialog — компоненты библиотеки.

Баланс в макете демонстрационный: начислено 2000, списано 600, в резерве 120,
доступно 1280. Резерв не считается списанием. Освобождение резерва не является
новым начислением. История различает начисление, резерв, списание и снятие резерва.

При реализации: считать доступный остаток на сервере; резервировать стоимость
до постановки задания в очередь; завершение обрабатывать идемпотентно, исключая
двойное списание; освобождать неиспользованный резерв при ошибке. Стоимость брать
из подтверждённого расчёта конкретной генерации, а не из демо-значений.
Фактический биллинг и ledger пока не реализованы. Добавленная авторизация — для
одного общего workspace, не многопользовательская изоляция.

Аватар аккаунта закреплён в левом нижнем углу Sidebar (Expanded / Collapsed / Empty). Меню открывается над аватаром; в ProjectHeader аватара больше нет.

Язык макетов и значений компонентов: English (en). Переведены все созданные экраны, состояния, тексты сценариев и демонстрационный контент.
